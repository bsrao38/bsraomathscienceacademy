# B.S. RAO GOLDEN 10™ — FULL ONE-PROGRAM MASTER

## Scale
- Classes 6–10
- 10 Golden Levels per class
- 4 stages per level
- 20 questions per test
- 200 tests
- 4,000 original questions
- Hall Ticket validation: 3827001–3827100
- +4 correct / -1 wrong / 0 unattempted
- Dynamic per-student question rotation

## Curriculum philosophy
Foundation: CBSE core.
Logical: CBSE competency/application.
Elite: CBSE-first with controlled ICSE, IGCSE and IB MYP-style exposure.
Master Challenge: CBSE mastery with selected international-style presentation.

The international curricula are used for exposure to presentation, application, inquiry and reasoning styles; they are not used to replace the student's CBSE syllabus or to force unrelated advanced topics.

## Class 10
The Maths and Science chapter lists are aligned to the chapter set specified for this academy. The 20-question format uses 10 Mathematics + 5 Physics + 5 Chemistry, matching the academy's existing test format.

## Dynamic retakes
Each test has a 20-question attempt. The browser records question IDs used by each Hall Ticket + class + level + stage. Retakes draw unused questions first. When that stage's 20-question pool is exhausted, the pool may recycle.

## Important quality note
The 4,000-question dataset is an original generated master bank intended to make the complete one-program engine functional. It should be teacher-reviewed before claiming it as a board-exam prediction bank. No question is guaranteed to appear in an actual board examination.
